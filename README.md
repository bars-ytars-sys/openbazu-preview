# Демо главной и разделов для открытьбазу.рф

Прототип структуры сайта. Не боевой сайт, страница закрыта от индексации.

Разделы: главная, услуги и цены, обучающие материалы, строительство,
калькулятор окупаемости, раздел для действующих баз.

Кнопка «Комментарии» в правом нижнем углу показывает пометки о том,
что изменено и что нужно согласовать.
